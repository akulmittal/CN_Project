# Full-Stack Demo Commands

Run these from the project root (`CN_Project/`). Tested on Linux with Mininet, OVS, and the project's SDN stack.

---

## Step 1: Build & Seed (One-time Setup)

```bash
# 1. Compile the C server binary
make -C online_exam_mvp

# 2. Initialize the SQLite database schema
sqlite3 online_exam_mvp/database/exam.db < online_exam_mvp/database/schema.sql

# 3. Start a temporary server to seed accounts and questions
./online_exam_mvp/exam_server --port 8080 --addr 127.0.0.1 --db online_exam_mvp/database/exam.db &
SEED_PID=$!
sleep 1

# 4. Seed 10 students, 10 questions, and generate users.csv
python3 online_exam_mvp/tools/seed_demo.py \
    --students 10 --question-count 10 --reset-users \
    --base-url http://127.0.0.1:8080

# 5. Stop the temporary seed server
kill "$SEED_PID" 2>/dev/null || true
```

> Student usernames (e.g., `student01`) and passwords are saved in `online_exam_mvp/users.csv` (mode 0600, git-ignored).

---

## Step 2: Terminal 1 — Start the SDN Controller

```bash
cd ~/Developer/CN_Project   # or your CN_Project directory
./sdn/scripts/run_controller.sh --mode sdn
```

*Leave this running. Controller listens on OpenFlow port `6653` and REST port `9090`.*

---

## Step 3: Terminal 2 — Start the Mininet Topology

```bash
cd ~/Developer/CN_Project
sudo -E python3 sdn/topology.py --students 10 --bw 10 --run-dir run/
```

*You are now at the `mininet>` prompt.*

---

## Step 4: Inside Mininet — Start Both C Backends & Frontend

Type these directly into the `mininet>` prompt:

```bash
# 1. Start Server 1 (Primary Backend)
mininet> srv1 $(pwd)/online_exam_mvp/exam_server --addr 0.0.0.0 --port 8080 --db $(pwd)/online_exam_mvp/database/exam.db --server-id 10.0.0.1:8080 --controller-url http://10.0.0.254:9090 > /tmp/srv1.log 2>&1 &

# 2. Start Server 2 (Standby Backend for Failover)
mininet> srv2 $(pwd)/online_exam_mvp/exam_server --addr 0.0.0.0 --port 8080 --db $(pwd)/online_exam_mvp/database/exam.db --server-id 10.0.0.2:8080 --controller-url http://10.0.0.254:9090 > /tmp/srv2.log 2>&1 &

# 3. Start the Frontend inside Student Host 1 (st1)
mininet> st1 bash -c "if [ -f sdn/scripts/start_frontend_in_mininet.sh ]; then bash sdn/scripts/start_frontend_in_mininet.sh; else cd online_exam_mvp/web && python3 -m http.server 80; fi" &
```

## Step 5: Open the App in Your Browser

### Option A — Direct (if host can reach `10.0.0.11`)

```bash
# Verify st1 is answering
curl -s http://10.0.0.11/health || curl -s http://10.0.0.11:80
```

Open browser at **`http://10.0.0.11`**

### Option B — Port bridge (if direct routing is blocked)

```bash
# Run in a separate terminal on the host
socat TCP-LISTEN:8081,fork,reuseaddr TCP:10.0.0.11:80 &
```

Open browser at **`http://127.0.0.1:8081`**

## Step 6: Live Demo Script for Faculty

### 1. Sign In & Take Exam

* Username: `student01` | Password from `online_exam_mvp/users.csv`
* Click **Sign in** → **Start / resume** → Answer a question → **Save answer**
* Watch **Terminal 1 (Controller)**: It receives `attempt_started` and automatically enables QoS (Priority 200) on the switches.

### 2. Show Controller State

```bash
curl -s http://127.0.0.1:9090/sdn/state | jq .vip
```

Expected output:
```json
{
  "backend": "srv1",
  "backend_ip": "10.0.0.1"
}
```

### 3. Demonstrate Instant Failover

In the `mininet>` prompt, kill Server 1:

```bash
mininet> srv1 pkill -f exam_server
```

*Wait ~4 seconds.*

Check VIP state again:

```bash
curl -s http://127.0.0.1:9090/sdn/state | jq .vip
```

Now shows:
```json
{
  "backend": "srv2",
  "backend_ip": "10.0.0.2"
}
```

In the browser, click **Submit exam** or **Save answer** — it succeeds immediately because all traffic was automatically rerouted to Server 2.

## Useful Debug Commands

```bash
# Controller health
curl -s http://127.0.0.1:9090/health

# Full controller state
curl -s http://127.0.0.1:9090/sdn/state | jq .

# Exam events received
curl -s http://127.0.0.1:9090/sdn/state | jq .exam.event_counts

# OVS flows on student switch
sudo ovs-ofctl -O OpenFlow13 dump-flows s_stu

# OVS flows on server switch
sudo ovs-ofctl -O OpenFlow13 dump-flows s_srv

# Ping all hosts
mininet> pingall
```
